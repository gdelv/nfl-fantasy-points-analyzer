# NFL Fantasy Points Analyzer

Season-by-season fantasy scoring for every notable QB, RB, WR & TE from 1999 through the 2025 season — career leaders, per-season charts, injury history, combine measurables, and 2026 contract data.

Built with React + Vite. Data: nflverse season-level player stats, weekly injury reports, and OverTheCap.com contract data (via nflverse).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Outputs a static site to `dist/`, deployable to any static host (Netlify, Vercel, etc.).
